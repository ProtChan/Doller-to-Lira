# ドルとリラ

USD/TRY（ドルリラ）のポジションと日次スワップを、ブラウザのローカル保存だけで管理する静的Webアプリです。

## 主な機能

- USD/TRYポジション追加・決済・削除
- 日次のUSD/TRY、TRY/JPY、1lotあたりスワップ入力
- 累積スワップ / 保有lot / 為替差損益 / 総損益の可視化
- 月次PnLカレンダー
- ロスカットライン推移
- 証拠金維持率推移
- localStorage保存
- JSONバックアップ / 復元
- CSVエクスポート
- GitHub Pages向け静的構成

## 計算前提

初期値は 1 lot = 10,000通貨、レバレッジ25倍、ロスカット閾値100%。すべて設定画面から変更できます。

USD/TRYの損益はTRY建てで計算し、各日または設定値のTRY/JPYでJPY換算します。必要証拠金は USD/TRY × TRY/JPY から合成したUSD/JPY相当を使って概算します。

## データ保存

データはサーバーへ送信せず、ブラウザの `localStorage` に保存します。ブラウザデータ削除に備えて「バックアップ」からJSONを定期保存してください。

## 公開

`.github/workflows/pages.yml` でGitHub Pagesへデプロイできる構成です。
