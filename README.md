# ドルとリラ

USD/TRY（ドルリラ）のポジション、スワップ、為替差損、証拠金リスクを記録・可視化する静的Webアプリです。GitHub Pages上で動作し、ユーザーのポジションや設定はブラウザの `localStorage` に保存します。

公開版: https://protchan.github.io/Doller-to-Lira/

## 主な機能

- USD/TRYポジションの追加・編集・決済・削除
- ポジション単体のFX損益・累積Swap・Net損益グラフ
- 日次のUSD/TRY ASK、USD/JPY、TRY/JPY換算値、Swapを管理
- ヒロセLION FXのUSD/TRY Swap履歴を参照して自動入力
- ヒロセASKの23時足終値を日次参照レートとして自動入力
- 日中最大ASKを使ったショート側のストレス・証拠金リスク確認
- 累積Swap / 保有lot / 為替差損益 / 総損益の可視化
- 月次PnLカレンダー
- ロスカットライン・証拠金維持率の推移
- 元本変更履歴を考慮した維持率 / LC計算
- JSONバックアップ / 復元、CSVエクスポート
- スマホと1366×768程度のノートPC向けレスポンシブ表示

## 現行の計算前提

初期値は **1 lot = 1,000通貨**、レバレッジ25倍、ロスカット閾値100%です。設定画面から変更できます。

USD/TRYのFX損益はTRY建ての値動きをJPYへ換算します。通常の日次評価では、USD/JPY ÷ USD/TRY から合成したTRY/JPYを使います。実口座の円換算レートが分かる場合は日次のTRY/JPYを上書きでき、決済済みポジションは決済入力時の実際の円換算レートを保存して最終FX損益に使用します。

必要証拠金はUSD/TRY × TRY/JPYから得られるUSD/JPY相当を基礎に、設定レバレッジで概算します。ロスカットラインは設定した維持率閾値を基準に推定する管理用の値です。

## Swapの表示・権利判定

ヒロセのSwap表にある **元データ日 D の金額を、次の営業日 C に表示**します。これはFX差損の日次推移と比較しやすくするための表示上のルールです。金曜などの元データは週末を飛ばして次の営業日に表示します。

ポジションごとのSwap権利判定は表示日を基準に、次の条件です。

```text
建玉日 < Swap表示日 <= 決済日
```

したがって、建玉日に画面上表示されているSwapは加算しません。一方、決済日に表示されるSwapは加算します。3日分・4日分などの金額はヒロセの元データをそのまま1つの金額として扱い、表示日だけを次の営業日へずらします。

例: 2026-09-09に新規建てした場合、9/9に表示される9/8元データのSwapは0円扱いで、最初の付与は9/10に表示される9/9元データ分です。

## レート・参照データ

アプリはリポジトリ内の公開JSONを参照します。

- `data/hirose-ask-close-23.json`: ヒロセUSD/TRY ASK 23時足終値とUSD/JPY
- `data/hirose-ask-day-high.json`: 日中最大ASK
- `data/hirose-usdtry-swap.json`: ヒロセUSD/TRY Swap履歴
- `data/user-prepared-rates.json`: 補助的なオーナー準備レート

参照データはGitHub Pagesから配信されますが、ユーザー自身のポジション・決済・設定・バックアップ対象データはブラウザの `localStorage` に保持されます。

## データ保存

ポジション、日次履歴、設定、元本履歴などのユーザーデータはブラウザの `localStorage` に保存します。ブラウザデータ削除や端末移行に備え、「バックアップ」からJSONを保存できます。

## CI / デプロイ

`.github/workflows/pages.yml` で、JavaScript検査とランタイムsmoke testに加え、Playwrightによる実ブラウザE2Eを実行します。

デプロイ前にローカルビルドをChromium / WebKitの両方で検証し、GitHub Pagesへのデプロイ後にも公開URLをChromium / WebKitで再検証します。Swapの翌営業日表示、建玉日除外・決済日包含、実測TRY/JPY、決済時円換算、レート履歴、レイアウト等も回帰テスト対象です。

> 本サービスは記録・可視化を目的とする管理ツールです。証拠金・ロスカット計算は設定値に基づく概算で、実際の判定は利用中のFX業者の取引ルールが優先されます。投資助言ではありません。
