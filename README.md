# ドルとリラ

USD/TRY（ドルリラ）のポジション、スワップ、為替差損、証拠金リスクを記録・可視化する静的Webアプリです。GitHub Pages上で動作し、ポジション・決済・元本履歴などのユーザーデータはブラウザの `localStorage` に保存します。

公開版: https://protchan.github.io/Doller-to-Lira/

## 主な機能

- USD/TRYポジションの追加・編集・決済・削除
- ポジション単体のFX損益・累積Swap・Net損益グラフ
- 配信された日次USD/TRY ASK・USD/JPY・TRY/JPY・Swapの閲覧
- ヒロセLION FXのUSD/TRY Swap履歴を参照したSwap会計
- 配信USD/TRY ASK 23時足終値とUSD/JPYを日次評価レートとして使用
- 日中最大ASKを使ったショート側のストレス・証拠金リスク確認
- 累積Swap / 保有lot / 為替差損益 / 総損益の可視化
- 月次PnLカレンダー
- ロスカットライン・証拠金維持率の推移
- 元本変更履歴を考慮した維持率 / LC計算
- JSONバックアップ / 復元、CSVエクスポート
- スマホと1366×768程度のノートPC向けレスポンシブ表示

## 日次データの方針

公開版の「日次データ」は **配信サービスの閲覧画面** です。一般ユーザーが日次レートやSwapを入力・編集・削除する機能はありません。

配信対象日に対しては、次の値を配信データから決定します。

- USD/TRY: 配信されたASK 23:00終値
- USD/JPY: 配信された23:00参照値
- TRY/JPY: `USD/JPY ÷ USD/TRY` の合成値
- Swap: 公開済みのヒロセUSD/TRY Swapデータを会計ルールに従って反映

従来版で保存されていた「手入力レート」「手入力Swap」「日次TRY/JPY手入力」などは、配信データが存在する日については配信値に置き換えます。配信範囲外にある古い日次履歴は削除せず、閲覧専用の旧履歴として保持します。

設定画面からも、日次レート入力方式、Swap入力方式、デフォルトSwap、日次TRY/JPY入力、参照データ再構築などの公開設定は撤去しています。元本、1 lot通貨数、レバレッジ、ロスカット閾値など、ユーザー固有の運用設定は引き続き変更できます。

## 現行の計算前提

初期値は **1 lot = 1,000通貨**、レバレッジ25倍、ロスカット閾値100%です。これらは設定画面から変更できます。

USD/TRYのFX損益はTRY建ての値動きをJPYへ換算します。通常の日次評価では、配信USD/JPY ÷ 配信USD/TRYから合成したTRY/JPYを使います。

決済済みポジションについては、決済入力時に実口座の円換算TRY/JPYを保存でき、その実測値を最終FX損益の円換算に使用します。これは日次データの配信レートとは別の、ポジション固有の決済情報です。

必要証拠金はUSD/TRY × TRY/JPYから得られるUSD/JPY相当を基礎に、設定レバレッジで概算します。ロスカットラインは設定した維持率閾値を基準に推定する管理用の値です。

## Swapの表示・会計上の計上日

ヒロセのSwap表にある **元データ日 D の金額を、次の営業日 C に表示し、会計上も C に計上**します。金曜などの元データは土日を飛ばして次の営業日に計上します。

このずらし方は、日次チャート上で **為替差損益が動く営業日と、Swapが計上される営業日を同じ横軸上で比較しやすくする**ための管理上のルールです。元のヒロセSwap金額そのものは変更せず、計上日だけを次の営業日へ移します。

ポジションごとのSwap権利判定も、この移動後の計上日 C を基準にします。

```text
建玉日 < Swap計上日 <= 決済日
```

つまり次の扱いです。

- **Swap計上日に新規建てしたポジションには、その日のSwapを付与しない**
- **Swap計上日に決済するポジションには、その日のSwapを付与する**
- 3日分・4日分などの複数日Swapは分割せず、元データの総額を次の営業日にまとめて計上する
- 土日はSwap計上日とせず、画面上のSwapは0円扱いにする

例: 2026-09-09に新規建てした場合、9/9に計上される9/8元データ分は対象外です。最初に対象になるのは、9/9元データを翌営業日の9/10へ移したSwapです。逆に9/10に決済する場合、9/10計上分までは対象に含めます。

## 配信・参照データ

アプリはリポジトリ内の公開JSONを参照します。

- `data/hirose-ask-close-23.json`: USD/TRY ASK 23時足終値とUSD/JPY
- `data/hirose-ask-day-high.json`: 日中最大ASK
- `data/hirose-usdtry-swap.json`: ヒロセUSD/TRY Swap履歴
- `data/user-prepared-rates.json`: 配信生成を補助するオーナー準備レート

公開版では、これらの配信値が日次データの唯一の公開入力源です。ブラウザ側に同期された日次スナップショットは計算・チャート表示用のキャッシュとして保持されますが、一般ユーザーから編集することはできません。

日中最大ASKはリスク表示にも使用し、日次終値とは別に「日中にどこまで不利なASKへ動いたか」を確認するための参照系列として扱います。

## データ保存

ポジション、決済情報、設定、元本履歴などのユーザーデータはブラウザの `localStorage` に保存します。日次データも表示・計算用スナップショットとして同期されますが、その公開値は配信データが正です。

ブラウザデータ削除や端末移行に備え、「バックアップ」からJSONを保存できます。

## CI / デプロイ

`.github/workflows/pages.yml` で、JavaScript検査、production bundleの構成検査、ランタイムsmoke test、Playwrightによる実ブラウザE2Eを実行します。

デプロイ前にローカルproduction buildをChromium / WebKitの両方で検証し、GitHub Pagesへのデプロイ後にも公開URLをChromium / WebKitで再検証します。

主な回帰検証対象は、配信専用の日次データ、旧手動モードから配信モードへの移行、Swap翌営業日計上、建玉日除外・決済日包含、複数日Swap、決済時円換算、ポジション編集、元本履歴、日中最大ASK、維持率・LC、スマホレイアウトです。

> 本サービスは記録・可視化を目的とする管理ツールです。証拠金・ロスカット計算は設定値に基づく概算で、実際の判定は利用中のFX業者の取引ルールが優先されます。投資助言ではありません。
